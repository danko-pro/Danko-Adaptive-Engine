# Заморозка adaptive-engine

Этот слой защищает `adaptive-engine` на этапе разработки adapter/UI.

## Что проверяется

Проверка сравнивает текущие файлы `adaptive-engine` с сохраненным слепком:

- список файлов;
- размер файла;
- `sha256` содержимого.

Если внутри движка изменился любой файл, общий `npm run check` завершится ошибкой.

## Зачем это нужно

Сейчас фокус проекта смещен на adapter/UI. Движок считается стабильной базой текущего этапа.
Любое изменение движка должно быть осознанным решением, а не побочным эффектом правок UI.

## Команды

Проверить заморозку:

```bash
npm run check:engine-freeze
```

Обновить слепок после осознанной разморозки:

```bash
npm run freeze:engine
```

## Роль ИИ

ИИ может читать вывод safety-system и предлагать патч. Но на этом этапе автоприменение патча не является
безопасным действием по умолчанию. Сначала человек смотрит причину, затем принимает решение:

- чинить adapter/UI;
- временно разморозить движок;
- обновить слепок движка.
