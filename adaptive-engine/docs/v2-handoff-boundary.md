# Граница передачи V1 -> V2

Этот документ фиксирует границу между стабильным V1 Geometry Engine и V2 Composition Engine.

## Главное правило

V1 и V2 не должны одновременно управлять поведением блоков.

Если работает защитная V1-проекция, V2 только наблюдает или не участвует. Если включен V2-сценарий, adapter не должен параллельно применять V1-проекцию.

## Где находится граница

Граница передачи находится в `engine-adapter`.

Причина простая: adapter уже видит вход UI, публичный фасад движка, текущие `items`, `metrics` и состояние выбора. Именно здесь можно решить, кто сейчас отвечает за координаты:

- V1-защита отображения;
- V2 Composition Engine;
- строгий режим без автоматического поведения.

## Режимы

Контракт режимов зафиксирован в `engine-adapter/contracts/adapterBehaviorModes.js`.

```text
off     -> ничего не применять автоматически
safe    -> включить старую защитную V1-проекцию
suggest -> adapter передает данные V2, V2 только предлагает решение
auto    -> adapter передает данные V2, V2 в будущем может вернуть применяемое решение
```

По умолчанию активен `off`. Это значит: блоки не должны сами смещаться только из-за изменения сетки. Ручная команда `v2 fix` остается отдельным действием.

## Что должен получить V2

V2 должен принимать базовые данные, которые уже доступны adapter-слою:

- `items`;
- `metrics`;
- `sourceMetrics`;
- `workspaceState`;
- `selection`;
- режим поведения;
- типы и смысловые роли блоков.

V2 не должен импортироваться в `adaptive-engine/core/index.js`.

## Что остается за V1

V1 остается строгим ядром:

- считает сетку;
- проверяет операции;
- возвращает ошибки и отказы;
- хранит публичные типы и отчеты;
- не принимает решений по автоматической перестройке layout.

Защитная подгонка adapter не считается V2. Это отдельный режим `safe`, который нужен только как аварийная страховка.

## Момент передачи

Adapter использует V1-проекцию только когда:

```text
shouldUseAdapterSafetyProjection({ behaviorMode }) === true
```

Adapter передает управление V2 только когда:

```text
shouldPassBehaviorToV2({ behaviorMode }) === true
```

Так V1 заранее знает, где отдать пас, а V2 знает, где его принять.
