# Knowledge layer

`safety-system/knowledge` — это память проекта для AI-шлюза.

## Зачем нужен слой

Раньше AI получал большой статичный промпт. Это дорого, шумно и плохо масштабируется.

Теперь AI получает:

- вывод ошибки;
- только релевантные документы;
- правила patch;
- ограничения текущего этапа.

## Как выбираются документы

`docsManifest.js` описывает документы и ключевые слова.

`selectRelevantDocs.js` смотрит на вывод проверки и выбирает документы, которые помогут чинить конкретную проблему.

`readKnowledgeContext.js` читает выбранные документы и собирает компактный контекст для prompt.

## Важное правило

Knowledge layer не чинит проект сам. Он только помогает AI получить правильный контекст.
