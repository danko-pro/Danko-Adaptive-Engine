# Debug UI

Этот раздел содержит только временные инструменты для проверки `adaptive-engine` в браузере.

- `config/` - переключатели debug-слоев.
- `icons/` - общие SVG-иконки debug-инструментов.
- `intents/` - временная проверка пользовательских намерений: выбор ячейки, выбор области и создание блока.
- `metrics/` - отображение снимка размеров и режима сетки.
- `operations/` - временный пульт проверки операций движка.
- `pointer/` - временные проверки указателя мыши.
- `probes/` - изолированные визуальные проверки отдельных ассистентов.
- `selection/` - временная проверка выбора ячейки или области.

Основной UI импортирует этот слой через `src/debug/index.js`, чтобы не привязываться к внутренней структуре debug-инструментов.
