# Workspace Zones

Этот слой дает V2 первичное понимание рабочей области.

V1 сообщает геометрию: количество колонок, строк и координаты блоков.

V2 поверх этой геометрии строит смысловую карту:

- горизонталь: `left`, `center`, `right`;
- вертикаль: `top`, `middle`, `bottom`;
- сектор: например `top-center` или `middle-right`;
- касание краев;
- растяжение на всю ширину или высоту.

Это не двигает блоки и не меняет layout. Это только описание положения, чтобы следующий слой мог принимать решения осознанно.

```text
V1 metrics -> workspace zones -> block position -> block role -> composition plan
```

Следующий уровень V2 добавляет `layoutIntent`.

`layoutIntent` не применяет изменения. Он только описывает ожидаемое поведение:

- `header` держит верх и ширину;
- `content` получает высокий приоритет;
- `sidebar` сохраняет боковую роль, но может переноситься;
- `control` должен оставаться рядом с управляемой областью;
- `warning` должен оставаться заметным и не перекрывать основной контент.

Главное правило: V2 не читает DOM как источник истины. Он получает подготовленный snapshot от adapter/host-проекта.
